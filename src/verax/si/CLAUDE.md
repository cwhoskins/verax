# `si` submodule

Simulates one net as a signal-integrity problem on a **native** transient engine: IBIS driver → package → board interconnect → IBIS receivers. Sits above `ibis/` and `pcb/`, below `analysis/` (whose `analyses/si.nim` and `evaluators/si.nim` adapt it); **no `spice/` edge**, so it runs without ngspice. The plan, decisions and what is still open: `docs/ibis_simulator_plan.md`.

- **`topology.nim`** — `SiNet`: data, not a `Netlist` (nodes, R/L/C/V, ideal line `(Z0, td)`, lossy line `(RLGC/m, length)`, driver + receivers with their IBIS package ports). `SiTemplate.build(TemplateParams)` is the parametric pre-layout net (point-to-point, daisy chain, star; series R, `n` vias, stub, parallel termination). `resolvePin` maps a pin through its `IbisBinding`; a `[Model Selector]` needs an explicit choice, `POWER`/`GND`/`NC`/unbound pins are unsupported by name. `TemplateParams.viaStub` only overrides when `hasViaStub` (use `templateParams(...)`).
- **`drive.nim`** — `Stimulus` (edge or bit pattern) → `Ku`/`Kd` `Pwl`s. A UI shorter than the waveform table truncates and **jumps** (warned).
- **`engine/`** — `pwl` (jump = two points at one time, right-continuous; `atLeft` for the left limit), `mna` (dense LU, companion models; `L = 0` and `R = 0` are exact branches), `bergeron` (lossless lines; linear interpolation of the delayed history), `newton` (PWL Newton, segment-change damping, KCL residual check), `transient` (the numerical policy — read its module doc before changing a number), `ibisdev`.
  - **Backward-Euler restarts happen only at discontinuous breakpoints** (a jump), not at every `Ku`/`Kd` knot — restarting at slope-only knots would make a whole vendor edge first order.
  - A line shorter than `tr/20` becomes a lumped π; trapezoidal rings at Nyquist on an LC far below `1/h` (tiny, tested).
  - Solver failure is a status (`ssSolverFailed`) naming time, node and step — never a waveform.
- **`simulate.nim`** — `SiNet + Stimulus → SiResult`: status first (`ssOk`/`ssUnsupported`/`ssSolverFailed`), then every node, and die-pad current = device current − `C_comp` current. Lossy lines become an RLGC ladder (section delay ≤ `tr/10`).
- **`measure.nim`** — flight time (IBIS: receiver crossing − driver's `Vmeas` crossing into its timing load, a tiny native run applied **at the die, no package**), overshoot/undershoot vs the driver's rails, ringback (after the first peak), monotonicity through the band, settle (absolute band), threshold margin. Curve primitives are `verax/waveform`.
- **`constrain.nim`** — the inverse question: sweep a template parameter on a grid, **bisect only between two valid samples** (an invalid point is a gap, never a fail), report passing *intervals*. Via-count and termination tables, stub-removal verdicts, rules of thumb, an `AnswerIdentity`; text/JSON report; `druRules` → `pcb/formats/kicaddru`.
- **`board.nim`** — `RouteTree` → `SiNet`. Refuses (unsupported, named) rather than guesses: no return path or partial coverage, a reference change (by plane **layer**) across sections or a via, a pour, a loop, an undeclared or unrouted pin on the net. `trace.rootedAt` keeps a flipped edge's sections in extraction order, so sections are re-ordered geometrically here.
