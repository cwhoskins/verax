# `si` submodule

Simulates one net as a signal-integrity problem on a **native** transient engine: IBIS driver → package → board interconnect → IBIS receivers. Sits above `ibis/` and `pcb/`, below `analysis/` (whose `analyses/si.nim` and `evaluators/si.nim` adapt it); **no `spice/` edge**, so it runs without ngspice. The plan, decisions and what is still open: `docs/ibis_simulator_plan.md`.

- **`topology.nim`** — `SiNet`: data, not a `Netlist` (nodes, R/L/C/V, ideal line `(Z0, td)`, lossy line `(RLGC/m, length)`, coupled pair `(Ze, Zo, td_e, td_o)`, Touchstone 2-port, driver + receivers with their IBIS package ports). **Several conductors**: `driver` is conductor 0; `extraDrivers` carry a `DriveMode` (`dmInverted` = a differential pair's other leg, `dmQuiet*` = a crosstalk victim); every port names its `conductor`; `diffReceivers` pair two receivers; `supply` (power-aware) gives the die rails every driver hangs from. A template's `partner` (`prVictim`/`prDiffPair`, point-to-point, no vias) couples a second conductor over `coupledLength` (a pair: throughout) with `spacing`/`diffR`/`legMismatch` parameters; a `channel` puts a Touchstone block before the receiver. `diffPartner` reads `[Diff Pin]` from either leg. `SiTemplate.build(TemplateParams)` is the parametric pre-layout net (point-to-point, daisy chain, star; series R, `n` vias, stub, parallel termination). `resolvePin` maps a pin through its `IbisBinding` (whose `pinMap` matched each netlist pin to a `[Pin]` row by name, else `signal_name` — a vendor file numbers package pins, a part may declare a subset); a `[Model Selector]` needs an explicit choice, `POWER`/`GND`/`NC`/unbound pins are unsupported by name. `TemplateParams.viaStub` only overrides when `hasViaStub` (use `templateParams(...)`).
- **`drive.nim`** — `Stimulus` (edge or bit pattern) → `Ku`/`Kd` `Pwl`s. A UI shorter than the waveform table truncates and **jumps** (warned). `complement`/`held`/`delayed` give the other conductors' stimuli.
- **`engine/`** — `pwl` (jump = two points at one time, right-continuous; `atLeft` for the left limit), `mna` (companion models; `L = 0` and `R = 0` are exact branches), `lu` (band LU with partial pivoting over a reverse Cuthill-McKee ordering — one path, a small net is dense at the same cost), `bergeron` (lossless lines; linear interpolation of the delayed history; a `CoupledLine` is two of them in modal variables, never lumped), `sblock` (a Touchstone 2-port by its impulse response in wave form, `h <= dt`; DC from `S(0)` as a pi), `convline` + `ratfit` (lossy lines by recursive convolution: fixed real poles, DC exact, exact step for piecewise-linear input), `newton` (PWL Newton, segment-change damping, KCL residual check, LU factor reuse), `transient` (the numerical policy — read its module doc before changing a number), `ibisdev`.
  - **Backward-Euler restarts happen only at discontinuous breakpoints** (a jump), not at every `Ku`/`Kd` knot — restarting at slope-only knots would make a whole vendor edge first order.
  - A line shorter than `tr/20` becomes a lumped π; trapezoidal rings at Nyquist on an LC far below `1/h` (tiny, tested).
  - Solver failure is a status (`ssSolverFailed`) naming time, node and step — never a waveform.
  - **Rail-referenced devices** (`NlDevice.refs`): a curve read at `v - (v(rail) - nominal)`, its current drawn from the rail; the LU **pattern must include the device↔rail entries** (`solverFor` adds them — without it the band LU silently drops them), and segment-change damping damps the rails too (a pad on a table knot with a moving rail otherwise oscillates). `Ksso` factors are lagged one step.
  - **Performance traps** (profiled, stage 7): never `for k, x in seq` in a per-step loop — `pairs` yields by value and deep-copies a device's tables; index with `template x = s[k]`. The LU factor is reused while `LinSolver.version` (bumped when the linear matrix changes: new `h` or integration) and every device's conductance are unchanged. When no device changes table segment the first Newton solve is exact and accepted (after the KCL check).
- **`simulate.nim`** — `SiNet + Stimulus → SiResult`: status first (`ssOk`/`ssUnsupported`/`ssSolverFailed`), then every node, and die-pad current = device current − `C_comp` current. A pattern run lasts at least its last bit. Lossy lines (`SiOptions.lossyModel`): **recursive convolution by default** (`convLineFor`; a line that kept its `LineSpec` uses `impedance.causalLine` over frequency, else constant RLGC; a fit worse than `convFitTol` or a line under the lumping threshold falls back to the ladder), or `lmLadder` (RLGC at one frequency, section delay ≤ `tr/10`). `impedance.rlgc` itself is **not causal** and cannot be fitted — never feed it to `ratfit`.
- **`measure.nim`** — flight time (IBIS: receiver crossing − driver's `Vmeas` crossing into its timing load, a tiny native run applied **at the die, no package**), overshoot/undershoot vs the driver's rails, ringback (after the first peak), monotonicity through the band, settle (absolute band around the caller's exact settled level, else the last sample — optimistic on a ringing net), threshold margin. `measurePattern`: each transition of a bit pattern on its own window to the next one; threshold margin read at the bit's end (ISI). Curve primitives are `verax/waveform`.
- **`sweep.nim`** — corner × stimulus × **probe**, worst value per probe per figure and the run that set it (`renderText`), every edge kept in `measured`. Probes (`probesOf`): signal receivers (an inverted conductor read with the opposite edge), differential receivers (`v(p) - v(n)` against `±Vdiff`, rails `±swing`; the legs only for overshoot), quiet victims' receivers and near ends (crosstalk, noise margin). A pattern of ≥ `eyeMinBits` bits is also folded into an eye (never skipped); `figuresOf` says what a probe reports. Both `analysis/analyses/si.analyzeSiNet` and `constrain.judge` run on it, so a check and a constraint measure identically. Settled levels are exact (`settledLevels`: DC with the driver held at the end of the edge's table); a still-ringing single edge is re-run 4× longer; ISI patterns (`isiPatterns`) run only when some edge does not settle within the UI (else an `Assumption` says why not). A figure undefined in any run is undefined; never-settles is `+Inf`.
- **`eye.nim`** — PRBS7/9/15/23/31 (O.150 LFSRs, all-ones seed) and `eyeOf`: the sampling offset searched over `0 .. maxOffset` (it absorbs the channel delay), height = worst 1 − worst 0 at the best offset, width = the open run of offsets with every bit past its threshold (≤ 1 UI).
- **`ssn.nim`** — `switching` + `quiet` copies of one output on shared die rails through `powerPins`/`groundPins` (parallel, no mutual L): ground bounce, power droop, quiet-line noise. The bounce peak comes at the onset of `dI/dt`, before `Ksso` (lagged) can act.
- **`constrain.nim`** — the inverse question (`judge` = one `sweepNet` per point; `Criteria.ui` adds the ISI patterns; `TimingRefs` caches the timing loads across a sweep): sweep a template parameter on a grid, **bisect only between two valid samples** (an invalid point is a gap, never a fail), report passing *intervals*. Via-count and termination tables, stub-removal verdicts, `spacingFor` (min gap to a victim: `minToEnd`), `spLegMismatch` (max pair mismatch), crosstalk/eye criteria, rules of thumb, an `AnswerIdentity` (with the partner); text/JSON report; `druRules` → `pcb/formats/kicaddru` (length, vias, clearance, skew).
- **`board.nim`** — `RouteTree` → `SiNet`. Refuses (unsupported, named) rather than guesses: no return path or partial coverage, a reference change (by plane **layer**) across sections or a via, a pour, a loop, an undeclared or unrouted pin on the net. `trace.rootedAt` keeps a flipped edge's sections in extraction order, so sections are re-ordered geometrically here.
