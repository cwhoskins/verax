# `spice` submodule

Runs simulations through ngspice and owns the simulation-only netlist transforms. Depends on `netlist`. The hub (`spice.nim`) exports the backend-agnostic pieces; `spice/ngspice` is opt-in per import. Every mutator here runs on a clone, never the design netlist. Use the `spice-model` skill when adding a device model.

## Simulation-only replacement — `Component.simModels`

A table of `SimReplacement`s set via the DSL's `simReplace`, inert until `transform.applySimReplacements` applies them. The analysis order is **clone → flatten → applySimReplacements → behavioural/pin-model passes → optional isolation**; some capacitor/source impedance passes follow isolation. Replacement-built `xspice.ports` is frozen text, so it must use post-flatten names. `materializeSimNetlist(nl, globalNets, purpose)` remains a clone-plus-recursive-replacement helper for already-flat netlists or hierarchical uses with **no subsequent flattening**, not the start of a flattening pipeline. Startup excludes the selected regulator from initial replacements and pin-model passes, then builds its replacement/ramp on the isolated fragment. **A part may carry several models**, because the right model depends on the question (averaged vs switching regulator).

- `simReplace` getter/setter is an accessor over the one table; `simDefault` names the default (empty = first added). Duplicate names raise.
- `SimReplacement.build` replaces the `kind`/`pinNets` shape entirely — needed for XSPICE code models, because `replaceComponent` never touches `nl.models` and the `.MODEL` card would otherwise be lost (the part would stop being passive and get dropped by `isolate`).
- **`transform.selectSimModel(c, purpose)`**: purposes name *what is asked* (`spOperating`, `spSmallSignal`, `spStartup`, `spSteadyState`, `spLargeSignal`), not which card. A model naming the purpose in `suits` wins; no match falls back to the default (`suits` is advisory); **two models claiming one purpose raises**.
- `replaceComponent` derives a fresh designator from `kind` (SPICE infers type from the letter). `clone` carries every model.

## Transforms

- **`isolate.nim`** — cut a *simulatable* fragment. Grows from seed components/nets through `kinds.isPassive` parts only (others land in `Isolated.dropped`). Terminates the cut: ground → `"0"`, other rails → ideal source at their stated voltage (**never guessed**; unknown raises unless `requireKnownRails = false`), open nets → 1 GΩ leak. **A rail is a boundary and never traversed through** unless it's a seed (one hop through VDD absorbs the board). `excludeRails` exists because an ideal source shorts the rail you're measuring at AC. A pinless `K` coupling is pulled in by a closing pass when both its inductors are selected.
- **`boundary.nim`** — connectors. A connector has nothing to pass through to; standing one in with per-pin impedances is wrong (a USB inlet read 0 V). `asSubcircuit` promotes connector nets to ports (named after the **net**) and drops connectors — composition only. `driveConnector` records drives as `boundary.*` pin attrs (data, not closures — `build` is `{.nimcall.}`), applied via `simReplace` so the connector stays on the BoM. Drives: `driveSource` (through its own `rout`/`lout`, never ideal), `driveLoad` (resistor — damps the PDN), `driveSink` (constant current — **open at AC, damps nothing**; use it for regulated loads), `driveOpen`. **`driveLoad` and `driveSink` are not interchangeable.** An undescribed port is left alone; an unknown port name raises. `instance ..., {"port": net}` wires **by name** and every port must be wired.
- **`flatten.nim`** — `flatten(nl, keep)` splices instances into the parent (innermost first), merging port nets via `hierNet`, merging ground, and merging child `.MODEL`s (hoist / drop identical / mangle conflicting). **Mutates in place.** A `keep` entry matching nothing raises. **Every analysis calls `flattenForSim` right after cloning and before any model pass** — the model passes only walk `nl.components`, so an op-amp inside an instance would reach the deck as `U1` (a distributed RC line). Lives in `spice/`, not `netlist/`, because flattening is a simulation-only concession.
- **`extract.nim`** — `extractInstance` (clone a child standalone) and `extractSubcircuit` (flat selection; boundary nets computed from the *original* graph become ports).
- **`probes.nim`** — `addVoltageProbe` is a label only. `addCurrentProbe` splits the pin onto a new net with a 0 V source (ngspice only exposes branch current for V sources/inductors); **refuses XSPICE code models** (their port text is baked into `xspice.ports`). `addImpedanceProbe` injects `DC 0 AC 1` so `v(net)` *is* Z in ohms.

## `backend.nim`

`SimVector` is an object variant (`sdReal` → `values`, `sdComplex` → `cvalues`). `[]` raises `SpiceSimError` on the wrong branch and `KeyError` on a missing name (`analysis/spice_fallback` depends on that). Complex helpers: `cplx`/`mag`/`db`/`phaseDeg`/`freq` (`mag` works on both kinds; `freq` takes the real part).

## `models/` — simulation-only device models

Every model invents numbers, so each returns `seq[Assumption]` (keyed, `annDefaulted`); a stated value produces no assumption. One file per model; `models.nim` re-exports and registers built-in behavioural stand-ins.

**The invariant** (`tests/test_spice_spellable.nim`, generated not listed): *a kind `isPassive` accepts must be spellable by the deck writer* — either `designatorPrefix` knows its letter or a model pass rewrites it. `expandPinModels` stands in for everything `isPassive` rejects; `isolate` absorbs everything it accepts.

**`expandPinModels` chain, most specific first**: a `subNetlist` or `simReplace` is honoured → a registered behavioural model (`registerBehavioralModel`, keyed by kind) → per-pin impedances by `Pin.kind` (low for `ptOutput` to ground, high otherwise, `ptGround` untouched) as **last resort**. Per-pin stand-ins **destroy any signal path** through the part. `BehavioralResult.handled = false` means **leave the part as is**, never "fall back to per-pin" (an LDO as two resistors reads 0 V — a confident wrong answer). `passesSignal` is declared, not inferred, so static checks know without simulating; `signalPathPins` is forwards-only.

- **Capacitors** (`capacitor.nim`, `derating.nim`) — series C + ESR + ESL from `esr`/`esl`, else a per-`package` typical, else a global fallback. Ideal caps show no ESR floor, SRF or anti-resonance. **Class 2 ceramics are DC-bias derated first** (the largest single correction here — up to ~7× on PDN impedance). `dcAcrossCapacitor` handles only the unambiguous case (one plate on reference, the other on a rail with stated voltage); otherwise 0 = unknown. Non-ceramic package families are never guessed into ceramics; missing `voltage_rating` assumed 2× working. Real bias loss depends more on case size than dielectric letter. C0G is exact (no bias dependence). Test fixtures that check closed-form identities use C0G for this reason. Modelling elements carry `parasitics.expanded` so they're never expanded.
- **Source impedance** (`source_impedance.nim`) — finite `rout`/`lout` (default 10 mΩ + 1 µH) on every source, because **an ideal source is a dead short at AC**. The default is defensible because the supply is in parallel with the decoupling. `rout = 0.ohm, lout = 0.H` opts back into ideal.
- **Ferrite beads** — `R‖L‖C` plus series `dcr`: `R = z_peak - dcr`, `L = R/(2π f_peak Q)`, `C = Q/(2π f_peak R)`, so the peak lands at `f_peak` by construction. `Q` defaults to 1; `value` is ohms if `z_peak` absent; `f_peak` defaults 100 MHz. A bead is not an inductor (an `FB` deck line is a CCCS).
- **`passives.nim`** — `wire`/`jumper`/`fuse` → resistor. **A fuse's `value` is amps** (`current_rating`); its resistance comes from `dcr`. Fuse blowing and trace inductance are not modelled.
- **`opamp.nim`** — `opampModel` (flat, for every unnamed op-amp) is emitted **flat, not as an `idealOpAmp` instance**, because `isolate` won't traverse a `subNetlist`. Reads `gain` and `gbw` off the part. Models gain, roll-off and 90° lag only. **Saturates only for a large-signal caller** (a `B` source `min(max(...))` between pole and buffer, rails from `supplyRailsOf` via the `V+`/`V-` nets): `min`/`max` has zero derivative at the limit, so clamping in `.ac` kills the gain of a stage biased at a rail. `vsatHeadroom` defaults to 0. Not registered for `comparator`. `idealOpAmp` returns a template netlist for `graph.instantiate`.
- **`regulator.nim`** — regulator kinds → ideal source at the **component's** `voltage`, never the net's (the net's is the requirement; reading it would make `dc_voltage` measure its own assumption). No stated voltage → declined with a note (carried on the failure path via `failBatch`).
- **`buffer.nim`** — buffers → unity VCVS (opening a feedback loop otherwise). Unity is a defensible default here, unlike a regulator voltage.
- **`magnetics.nim`** — `transformer`/`common_mode_choke`/`coupled_inductor` → two windings (L + DCR) and a pinless `mutual_inductance` `K` per pair. Inductances from `lpri`+`lsec`, else `lpri`+`turns`; **neither → left unmodelled with a note** (no defensible default). `k_coupling` defaults to 0.98. No core loss/saturation/interwinding C. Switching flyback primaries have no model.
- **`switch.nim`** — `expandSwitches`: two-terminal switches → `S` element + `.MODEL SW` (`ron`/`roff`/`vt`/`vh`). `muxModel` (behavioural, `passesSignal`) for `analog_switch`/`rf_switch`/`mux`: per-throw decoder as a **product of logistic terms** (a hard step breaks `.tran` timestep control and `.ac` linearisation), a through `S`, and optional absorptive termination (`switch.off_termination`). **Snapshot every net name before `removeComponent`.**

## `ngspice.nim`

- `run(nl, analysis, setup)` — **one analysis per call** (ngspice's `write` keeps only the last plot). Setup cards (`.ic`, `.nodeset`, `.options`, `.param`, `.temp`) are not analyses and are written first; a known analysis card in `setup` raises; unknown cards pass through. The `run(nl, cards)` overload still refuses more than one card.
- `.ic` forces `uic`, which skips the operating point (un-named nodes start at 0) — declared as an assumption.
- **Success = a parseable rawfile exists**, not the exit code. **A parseable rawfile is not a solution**: the log is scanned for `singular matrix`, `iteration limit reached`, `too many iterations`, `no convergence` and the run raises naming the node. `gmin stepping failed`/`source stepping failed` are deliberately *not* fatal (ngspice usually recovers).
- Rawfile is ASCII (`set filetype=ascii`); `.ac` values are `real,imag` with no spaces.
- `codemodels` are unioned with `xspice/instance.collectCodeModels(nl)`; `pre_codemodel` lines lead the `.control` block.
- `$VERAX_KEEP_DECKS` copies decks; `$VERAX_KEEP_RUNS` makes ngspice *write* `runNNN.cir/.raw/.log` there (plus `.svg`/`.json` through the `setRunPictureWriter` hook, installed by `verax/run_archive` — `spice` has no `schematic` edge) and appends an `index.txt` row (failed runs too). Analyses pass a `label` (`pdn:vdd`).
- ngspice already saves every node voltage and V-source/inductor `#branch` by default. `$VERAX_SAVE_CURRENTS` adds device internals via `saveCurrentsCard`: **`all` must lead** the list (naming any vector disables the default set), and it is **never emitted for `.ac`** (real tokens in a complex plot break `parseRawfile`). Don't use `.options savecurrents` (frontend-only, logs `unknown option`).
- `branchCurrentVector`: `V`/`L`/`E`/`H` are `i(l1)`; others are `i(@r1[i])` and must be `.save`d.
- Probing an internal node of a nested instance by hierarchical path is unsupported — `extract` it first.
