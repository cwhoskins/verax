# `report` — the simulation test report

`verax report designs/foo.nim -o out.html` (or `check --report=`). One self-contained HTML file; `.pdf` converts it when a headless chromium/weasyprint/wkhtmltopdf is on `PATH`, otherwise keeps the HTML and says so. Sits above `readiness`, `spice`, `schematic` and `plot`; below `verify`, which imports it for the flag.

## Pipeline

- **`collect.nim`** — `collectReport(d, allowed, board)` is `readiness` with every ngspice run kept. **Curves never enter `Readiness`** (`verify` pins its size): they arrive through `spice/ngspice.setRunObserver`, attributed to a plan step by the `onStep` hook `readiness` threads into `EvalContext`. `runsOf(report, check)` keys on `Check.step`, not the check's index. The observer is cleared in a `finally`. A shared `.op` cached in `scratch` belongs to the first step that ran it; later steps show "reused an operating point".
- **`content.nim`** — `buildModel` turns that into a renderer-neutral `ReportModel` (a LaTeX backend would consume the same model). Tests with at least one verdict come first, failures first; checks that ran but produced no verdict, every unchecked claim, and every rejected claim go to **Inconclusive / not run** at the end. A partly-unchecked test keeps its section and cross-links its unchecked claims there.
- **`html.nim`** — `renderHtml`. Inline CSS (dataviz reference tokens, dark mode, A4 print rules: one test per page, logs opened before printing, decks hidden), inline SVG, and a small script: plot crosshair readout (reads `plot`'s `data-xmap`/`data-ymap`) and click-to-zoom schematics. No external resources — a test checks that.
- **`pdf.nim`** — `htmlToPdf`, never raises; verax requires no converter.

## Rules

- **Plots show only what a claim names**: subject nets, nets the evaluator's `setupDoc` names as `net 'x'` (where it injects and reads — so keep that phrasing in new `setupDoc`s), and a result's ` at net 'x'`. Matched `v(net)` case-insensitively, else a unique hierarchical suffix. No match → no plot, and the figure says which nets had no vector. Never fall back to "the first few vectors".
- **A limit is drawn on a curve only for `overlayQuantities`** — quantities that *are* a level on the subject net's own trace, in the trace's unit. `ripple_pp` is in volts too, but a ripple limit on V(t) would read as an absolute level. Add a quantity there only if that holds. AC traces switch to |V| in ohms (log axis) only when an impedance claim is present (the PDN evaluator injects 1 A); otherwise dB.
- `at_f` conditions and measured frequencies (`unit == "Hz"`) become vertical lines on AC plots.
- `.op` runs (one point) become a node-voltage table, named nets first.
- **The picture is a view (`view.nim`), never a whole netlist.** Source: the first run's simulated netlist, else (no run: static, SI, reused `.op`) the design flattened once. Seeds: the run's `BenchInfo` (focus, stimulus/load/probe nets and parts), the claims' `scope` (else subjects, via `flatName`), and the claim role's other signal nets for context (SCL beside SDA). Growth (`growRegion`): through two-terminal passives and fixture parts up to `viewHops`, shrinking to fit `viewMaxParts`; ICs, sources and instances are boundary blocks; ground never walked, other rails only when seeded; **an IC given as a seed is a block, not a seed** (an MCU's 144 nets would flood). **Folding**: `bench.role` model/stand-in elements are drawn as their `bench.of` design part (all of a part's elements fold, in reach or not); a folded macromodel's pin takes the simulated element's net when the pin names match (`normPin`), so a broken loop shows the break. 0 V current-sense sources are listed, not drawn, and their split net merges back. Parts over `pinTrimMin` pins show only pins on the view's nets. Layout runs **unbundled** (no bus/array collapse: SDA and SCL drawn as themselves). Orange = read, blue = driven (`renderSvg` highlight classes). Layouts are cached by `viewKey`. **Layout is the report's dominant cost** — never draw a whole board.
- Each test has a **Test bench** block: scope strategy and its doc, stimulus/probe/load/termination rows, detached and cut-away parts, and the folded models.
- Log notes keep warning/error/convergence lines; the two notes ngspice prints on every run are dropped. The full log is always attached.
