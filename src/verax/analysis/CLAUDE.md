# `analysis` submodule

Answers questions *about* a netlist, from graph walks to full simulation. Depends on `netlist`, `spice` and `si` (the native SI engine).

**Two result types.** `Issue` is a finding; a check **never raises** on a netlist-content problem — the problem is the return value. `AnalysisReport` is a measurement: `Measurement`s, implied `Issue`s, the `SimResult` curve, and `assumptions`.

**`assumptions` is load-bearing**: every invented input (soft-start ramp, package ESL, ideal op-amp, rail source, leak resistor) is an `Assumption` record so it can be counted/filtered (`invented()`).

**Layout.** Root holds only toolchain-free modules (`issue`, `io_check`, `measure`, `report`), exported by the hub. Simulator-backed analyses are opt-in, one file each under `analyses/`, returning an `AnalysisReport` and knowing nothing of contracts. `evaluators/` adapts them to `contract` (mirroring `contract/roles/`; basenames deliberately match the analysis they wrap). `evaluators/contract_eval.nim` registers everything and is what `verify.nim` imports.

## Cross-cutting rules

- **Don't isolate when the boundary would invent the answer.** `runDcVoltage`, `transient`, `dcsweep`, `psrr`, `derating` simulate the design as authored — a rail terminated at its nominal by an ideal source measures its own assumption. Only `pdn`, `startup` and `opamp` isolate.
- **Model-pass order around isolation**: `expandPinModels` runs **before** `isolate` (which drops unmodellable parts), with the analysed part in `exclude`; `expandSourceImpedance` and capacitor parasitics run **after**, on the fragment. `modelUnmodelledParts = false`/`modelSources = false` restore cut-at-boundary/ideal behaviour.
- **Adapters run analyses in measurement-only mode** — the assertion is the authority. The disabling values differ and are verified: `targetZ`/`overshootLimit`/`maxPeaking` need `Inf`, `minPhaseMargin` needs `-Inf`, `currentLimit`/`minBandwidth` are disabled by `0`. Non-limit issues still ride along.
- **Anything not found is `NaN`**, never raised or clamped. `NaN` reads as notEvaluated downstream.
- **One producer per quantity** (`registerEvaluator` enforces it). Hence `spice.transient` doesn't declare `final_v` (`spice.startup` does), and `spice.dc_sweep` serves both sweeps, chosen by a `sweep` condition.
- **Setup keys carry everything that changes the run**: swept range, step magnitude, `step_band`, band, `at_f`.
- **Signs**: a branch-current sign is a deck convention; rating figures are magnitudes. Channel order is authoring order; match figures are magnitudes/ratios ≥ 1.
- Attrs read by analyses: `Net.attrs["voltage"]`, `Component.attrs["esr"/"esl"/"package"]`.

## Modules

- **`measure.nim`** — re-exports `verax/waveform` (moved down so `si/` shares it; edit it there). Pure curve math, testable offline; most reasoning lives here. `harmonicAmplitudes`/`thd` integrate over the samples' **own timestamps** (no resampling — ngspice's small steps are where the harmonics are) across the **last whole number of periods**; < 2 periods → `NaN`. Frequency helpers pass `logX = true`. `corner3dB` references the first swept point (right for DC-coupled); `gainMax`/`bandEdges` reference the maximum (right for AC-coupled); no shape detection is attempted. `fundamentalFreq` counts rising crossings of the window **mean** with hysteresis (not an FFT — resolution); < 2 crossings → `NaN`. `timeMean`/`timeRms` weight by elapsed time; `timeRms` integrates the square exactly for piecewise-linear data. `maxDeviation` requires both curves on one axis. Malformed input (empty/mismatched arrays) raises.
- **`io_check.nim`** — static checks (`analyzeIO`). **`checkRailVoltages` is a structural `sevWarning`, not an assumption**: a rail with no stated voltage is cut loose as a floating node at isolation, which changes topology (it once turned a gain-65 stage into a follower with every claim passing). The message names the components that lose their connection, skipping bypass caps. Classification tables are in `netlist/kinds` (re-exported).
- **`analyses/operating.nim`** — one `.op`, solved once per `EvalContext` (`evaluators/common.sharedOperatingPoint`, under `scratch["spice.operating_point"]`). Straight-line, not a fixed point, because **the DC operating point doesn't depend on capacitance** — so derate ceramics from actual node voltages, then run `.ac`/`.tran`. `voltageAt` is `NaN` for an unseen node (≠ 0). Limit: a `.tran` bias moves with time.
- **`analyses/derating.nim`** — part usage within ratings: one non-isolated `.op`; `voltage_rating` vs DC across, resistor `power_rating` vs V²/R. Ceilings per dielectric family (tantalum 50% — fails short; ceramics' capacitance loss is already modelled). **`current_rating`/`isat` are not checked here** (not in an `.op`) — `transient.analyzeCurrent` does it.
- **`analyses/dcsweep.nim`** — `.dc` (its own capability). `analyzeLineSweep` sweeps an existing source (resolved after flattening, identified by `deckDesignator`; a non-`V` part is refused); `analyzeLoadSweep` **injects** a constant-current sink (a test load isn't a board part; a resistor would sweep the drive too). No capacitor parasitics, no source impedance (it would add to `z_out_dc`). **`dropout_v` is `NaN` with `KindNoDropout` when regulation never broke** (also what ideal regulator models always report). Percentages reference the least-stressed end (high line / light load).
- **`analyses/pdn.nim`** — rail impedance vs frequency: isolate with the rail *excluded* from termination, parasitics on, 1 A AC, sweep to 1 GHz. Reports `z_min`/`f_z_min`, in-band worst, `z_at_<f>`, and `z_antiresonance`/`f_antiresonance`. **Target band is bounded (100 kHz–100 MHz)**: below, the regulator holds the rail (cut away); above, plane/package inductance isn't in a netlist.
- **`analyses/startup.nim`** — `.tran` ramp-up/inrush. Without a `simReplace` the regulator becomes an ideal source on an assumed soft-start ramp — **no loop, current limit or dropout**. `measureNet` may differ from `outputNet` (post-filter ringing). **Every rail downstream of the regulator (`downstreamRails`, walking passives only) is seeded and left unterminated** — an ideal source on a downstream rail drives current backwards (2.8 kA vs a true 163 mA). A regulator's own model is honoured including `build`; the inrush probe looks for a pin on the output net (none → no `inrush_peak`, not zero); `StartupStart.ssAuto` uses `uic` from zero when the part brought a model (an `.op` would start at the end of the ramp).
- **`analyses/transient.nim`** — one `runWindow` shared by four analyses (same netlist/window/`uic` so they can't diverge). Not isolated. **`tSettle` is stated, not detected.** Capacitor parasitics on (ripple is mostly ESR). **The print step caps ngspice's internal timestep** — `analyzeOscillation` passes 10× `windowSamples` for frequency accuracy. `initialConditions` → `.ic` + `uic`.
  - `analyzeTransient`: `settled_v`, `ripple_pp`, `settled_min/max`, `final_v`.
  - `analyzeOscillation`: frequency first (THD needs it); `NaN` frequency → `KindDidNotOscillate` saying "never moved (kick it)" vs "not periodic (widen window)".
  - `analyzeCurrent`: per-part `i_peak`/`i_rms`/`i_avg` (magnitudes), `i_min`/`i_max` (signed), `*_derating` vs the part's own rating (`NaN` if unstated, not infinite headroom). Subject is a part, not a net. **Setup key is the window only** (one run serves all parts; `harvestPart`/`Measurement.at` keep answers apart). **Three-terminal devices are refused** (which current?). Current vector names via `ngspice.branchCurrentVector`.
  - `analyzeLoadStep`: injects pulsed sink `ILOADSTEP` via `runWindow`'s `mutate` hook. Baseline = pre-edge time mean; recovery measured against the **new** settled level within `settleTol` (default 1% — **state it when the droop is smaller**, or recovery reads zero). `tHold = 0` skips the release.
- **`analyses/psrr.nim`** — **two methods, deliberately two evaluators** (different capabilities; one evaluator needing `{ac, tran}` would be refused on a host offering one). `analyzePsrrAc` (`psrr_min_db`, `f_psrr_min`, `psrr_at_f`); `analyzePsrrTone` (`psrr_db`, `in_ripple_v`, `out_ripple_v`). Ripple is injected by **re-netting the supply's output pin** and inserting the source (works for any value string; composes with source impedance). **Input ripple is measured**, not assumed. **An output at the noise floor is refused** (`KindNoFeedthrough`) — usually an ideal-source regulator stand-in or a code model with no `AC_GAIN`. The tone method checks against noise at `f0·√2` and `f0·√5`.
- **`analyses/opamp.nim`** —
  - `checkFeedback`: pure walk output → inverting input through passives, *including blocking parts* (integrators).
  - `analyzeLargeSignal`: sine drive; THD, swing, clipping, compression. **The stimulus carries the node's own DC bias** from a prior `.op` (`SIN(0 ...)` would clamp a mid-rail node).
  - `analyzeOpAmpResponse`: closed-loop, **two reference sets**: `gain_dc_db`/`bw_3db`/`peaking_db` (first point) and `gain_max_db`/`f_gain_max`/`f_lo_3db`/`f_hi_3db` (maximum); plus `gain_at_f` when `gainAtFreq > 0` (`NaN` outside the sweep).
  - `analyzeLoopGain`: break at the inverting input, `T = -V(A)/V(B)`. **Phase margin is never read off the closed-loop curve.** Gain margin is `NaN` for ≤ 2 poles. **The break is validated**: if low-frequency phase isn't near 0/180, there's more than one 0 dB crossing, or the margin is outside (-180, 180], both margins are `NaN` with `KindLoopBreakInvalid` (a Sallen-Key's second feedback path stays closed and read 450°).
  - Pin roles matched **by name** (`+`/`IN+`/`INP`, `-`/`IN-`/`INN`, `OUT`/`VOUT`); unmatched raises listing the pins.
  - **`checkInjectionPoint` refuses to drive a node inside the loop**: driven net is one of the amp's input pins' nets **and** the output reaches it through passives (not traversing rails). Either alone over-triggers.
  - A stated `gbw` beats the 1 MHz macromodel default.
  - `detachDrivers` removes stiff drivers on the driven net (two ideal sources → singular matrix).
- **`analyses/match.nim`** — `analyzeChannelMatch`: calls `analyzeOpAmpResponse` per channel. `gain_delta_max_db` (band) vs `gain_delta_at_f` (point) are separate names. Magnitudes / max-over-min ratios. **Frequency axes are checked identical** (Issue if not). Assumptions/issues merged and deduplicated. Either sweep failing → all `NaN`.

- **`analyses/si.nim`** — the SI net, on `si/` (no ngspice). `analyzeSiNet(pcb, nl, req)`: every corner the IBIS data supports (min/max only when complete — no substitution policy), both edges, and with `req.ui` (the role's `ui`) the ISI patterns — all through `si/sweep.sweepNet`; one report per receiver with the **worst** value and `at = "<pin>, worst at <corner> <edge or pattern bit>"`. A figure undefined in any run is `NaN` (an `si_undefined` issue), never the worst of the runs that produced one. Never-settles is `+Inf` (fails a budget), not `NaN`. IBIS files come from `ibis_file`/`ibis_component`/`ibis_model` (cached by absolute path). `deriveSiConstraints` is `verax constraints`: a template on `defaultStackup` (every figure an `Assumption`). With a victim (`SiNetRequest.hasVictim` + `coupledLength`) it also derives the **minimum spacing** on a route that is exactly the parallel run (a route at the length rule's limit would fail its own flight time whatever the gap). With `req.eyeBits` the sweep adds a PRBS7 and the reports carry `si_eye_height_v`/`si_eye_width`. `deriveDiffConstraints` (a `diff_pair` with `driver`/`rx`): the N leg from `[Diff Pin]`, `Vdiff` from the receiver's row or `[Receiver Thresholds]`, the pair's width solved for `z_diff` with gap = width, the termination found across the pair in the netlist; max length and max leg mismatch (tightened by `skew_intra_max` over the line's delay).

## Evaluator notes

- `evaluators/common.nim`: `harvest`, `failBatch` (carries assumptions on failure so notes survive), `subjectNet`/`subjectComponent`/`bindingName`, `transientWindow`, `sharedOperatingPoint`.
- `opamp.nim` holds `opamp_response`/`large_signal`/`loop_gain` (shared `opampSetup`/`opampKey`).
- `spice.channel_match`: `arity 2..2`, `subjectKinds {skClass}`, `binds` `opamp`/`input`/`output`.
- `i_out_derating` is a `spice.current_path` quantity (batches into the same `.tran`); `NaN` without the regulator's `current_rating`.
- Both PSRR evaluators bind `source`/`input`, so a bare `require` names the role it needs.
- `si.net` (`evaluators/si.nim`): `needs {capSiTran}`, pin subjects, binds `net`/`driver`, one run per `si_net` instance (setup key = origin). Crosstalk claims (`siCrosstalkQuantities`) are always notEvaluable on a board: coupled-trace extraction does not exist; `verax constraints` derives the spacing instead. The board comes from `scratch[boardScratchKey]`; none → `esNotEvaluable` pointing at `--board=` and `verax constraints`. Unsupported → notEvaluable, solver failure → notEvaluated.
