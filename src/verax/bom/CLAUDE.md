# `bom` submodule

Compiles a bill of materials: which real, orderable part each component is. `docs/bom_compiler_plan.md` is the plan. **Shipped through Stage 4** (collect, source registry, offline JSON catalogue, resolver, report/lockfile, `verax bom`). **Still to build: network sources** (and the disk cache, which caches network answers).

**Placement.** Above `parts/`, below `verify.nim`; imports `netlist` and `units`, **never `pcb`, `spice` or `contract`**. Takes a `Netlist`. Not in the verification path. `pcb/bom.nim` (BoM from a board file) is separate; reconciling the two is a non-goal.

## Conventions

- **Unknown is `none`, never `0` or `NaN`.** `BomItem` ratings are `Stated[float]` (keeping the annotation's provenance — a `parts`-derived or `bom:`-defaulted rating is not the designer's; JSON `requirement.sources`); `BomItem.value`, `Candidate` numbers, `PartQuery` requirements and `Availability.stock`/`moq` are `Option`. Unknown stock never triggers a low-stock finding. Lockfile signatures still print an unstated number as `-`, so old locks match.
- `pfNotAPart`: simulation-only kinds (sources, `K` couplings, controlled switches) are left off by kind.
- `designators` is what the line prints (hierarchical path, or `package.ref` — a dual op-amp is bought as `U9`); `members` lists every section path.
- `partNumber` is kept verbatim, never written into `mpn`; `effectiveMpn` reads `mpn` then `partNumber`. Free-text labels live in `description`.
- Findings live on `BomItem.issues` / `Resolution` / `BomResult.issues`, not side lists.

## Modules

- **`classify.nim`** — `familyOf` (runtime table, `registerPartFamily`; kinds are open strings, never a `case`). **`caseCodeOf` is the standard-footprint gate** → imperial chip code or `""`. A stated `footprint` is the only authority when present; a footprint name is read only when the imperial code sits beside its metric twin (`R_0402_1005Metric`) because `0603` is both a real imperial and metric size. Without a footprint, `package` must be a bare imperial code. `""` means: don't search.
- **`collect.nim`** — one `BomItem` per physical part (leaves from `netlist/graph.leafComponents`, shared with `pcb/assemble`). Groups sections by `package.ref`. Parses `value` with `parseSpiceMagnitude` **only for the four parametric families** (elsewhere it's a model name; `1N4148` is lexically RKM); RKM → `bom_value_unparseable`. `dnp`/`bom_exclude` set flags; excluded parts are kept with the flag. Partially-DNP package → `bom_package_dnp_conflict`, treated as DNP. **`bom:` defaults** (from the netlist of the first member) fill only unstated fields of parametric parts, each recorded as an `Assumption`; a default package applies only when neither `package` nor `footprint` is stated.
- **`source.nim`** — `CatalogSource` registry: registration order = resolution order, `nil` procs skipped, **nothing registers on import**. Procs are **closures** (sources carry state). A default-constructed `PartQuery` asks for nothing beyond family/value/case code. **`matches` is the one definition of a match**: family and case code equal (`""`/`none` matches nothing), value within `valueTolerance`, and a stated minimum rating/dielectric/max tolerance **rejects a candidate that leaves it unknown**. `manufacturers` is a ranking hint, never a filter. `searchAll` dedups on `partKey` and returns `copyCandidate`s. `clearCatalogSources` for tests/reruns.
- **`sources/local.nim`** — `verax.catalog/1` JSON, loaded whole, scanned linearly (no SQLite — would break the stdlib-only rule for no gain). **Strict**: SI numbers only (no `"10k"`), tolerance a fraction (`>= 1` refused), unknown fields/families/lifecycles/case codes refused, parametric rows must state `value` and others must not, duplicate `(manufacturer, mpn)` refused. All errors collected into one `CatalogError`; nothing loads from a bad file. Not registered on import — `registerCatalogFile(path)`.
- **`resolve.nim`** — per item: **excluded** (`bom_excluded`) → **MPN for every family** (stated `mpn` authoritative; unknown → `bom_part_not_found` warning, kept as stated; no `mpn` → `partNumber` with `bom_partnumber_used_as_mpn`, info if a source knows it, warning if not; `bom_mpn_spec_mismatch` when the part contradicts design specs) → **parametric search** → `bom_mpn_required`/`bom_no_match` (`sevError` only if the part reaches assembly). **A candidate's whole tolerance band must fit inside the item's** (`fitsBand`). **Ranking: lifecycle first**, then preferred manufacturer, exact value, stock (unknown last), MPN, manufacturer. `signatureOf` (requirement only, never designator) is the lock key; a lock wins only if still a non-obsolete candidate, else `bom_lock_stale`. Search still runs under a lock. Roll-up keys on `partKey` + DNP; unresolved items share a line per signature. `bom_low_stock` is per line. Of `bom:` defaults only `manufacturers` is read here; **`series`/`derating` are not read**. `bom_no_sources` once when nothing is registered.
- **`report.nim`** — `render` (text), `renderCsv` (RFC 4180; excluded parts on no row), `renderJson` (`verax.bom/1`, hand-built, `jnum` for `NaN`/`none`→`null`, unknown stock/MOQ `null`). JSON has `parts[]` (all items) and `lines[]` referencing parts by index. **It is also the lockfile**: `parseLock`/`loadLock` read parts that have a `signature`; one signature tied to two parts is refused (`LockError`).
- **CLI** (in `verify.nim`/`cli.nim`): `--bom` or any `--bom-*` flag selects `compileBom`, which runs before `readiness` and stops. Unknown `--bom-*` flags are errors. Catalogues from repeatable `--bom-catalog=` else `$VERAX_BOM_CATALOG` (`PathSep`-separated). Exit `exitStructural` if an assembled part is unresolved, else `exitClean`; unreadable catalogue/lock → `exitCompile`. With CSV/JSON on stdout, findings go to stderr.
